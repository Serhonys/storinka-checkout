# Storinka Checkout 1.0.1

Одна сторінка замість шести кроків. Ця збірка лише для **ocStore 3.0.4.1** (і сумісного OpenCart 3.0.x з тими самими шляхами `extension/module`).

Інсталятор **нічого не пише** в `catalog/controller/checkout`. Увесь код модуля лежить у `catalog/controller/extension/module/storinka.php`. Штатний `checkout/checkout` лишається на місці: його підміняє подія `catalog/controller/checkout/checkout/before`. OCMOD у `install.xml` лише запасний шлях і кладе копію в `system/storage/modification`, оригінал `checkout.php` не перезаписує.

Замовлення збирається як штатний `checkout/confirm`: ті самі totals, товари, affiliate і модулі оплати. Порожній заказ не створюється, поки покупець не натисне підтвердження. Повторне натискання оновлює чернетку зі статусом 0.

## Архів

`dist/storinka-v1.0.1-ocstore-3.0.4.1.ocmod.zip`

## Встановлення

1. Розширення → Установник → завантажити zip. Якщо стояла 1.0.0, спочатку видаліть її (вона клала файл у `catalog/controller/checkout`).
2. Розширення → Модулі → Storinka → Встановити → Редагувати.
3. Увімкнути статус і зберегти. Кнопка «Встановити» реєструє подію, цього досить, щоб сторінка замінилась.
4. Розширення → Модифікації → Оновити — лише для запасного OCMOD.
5. Вимкнути Simple, Ajax Quick Checkout і швидке оформлення теми.

Посилання «Стандартне оформлення» відкриває штатну сторінку з `storinka_off=1`.

## Що налаштовується

- Поля: показ, обов'язковість, ширина, порядок. Для UA за замовчуванням обов'язкові ім'я і телефон, email необов'язковий, країна і регіон сховані і беруться з налаштувань магазину.
- Країна без регіонів не блокує доставку: `zone_id` стає 0.
- Самовивіз (`pickup`) не питає адресу.
- Матриця `доставка = оплата`. Перший збіг виграє. Приклад: `pickup.pickup = cod`.
- Нова Пошта: коди методів, API-ключ, місто, відділення або поштомат. Без ключа лишаються звичайні поля. Ціну дає модуль доставки магазину.
- Купон, кількість у підсумку, маска `+380`, акцент і радіус.
- Кастомні поля акаунта й адреси (крім типу file).

Мови: uk-ua, ru-ru, en-gb.

## Чого модуль не робить

Не вставляє чужий віджет доставки у свою верстку. Якщо модуль Нової Пошти вміє лише малюватись у старому `shipping_address.twig`, його треба вимкнути або відкрити стандартне оформлення за посиланням.
