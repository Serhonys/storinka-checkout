# Storinka Checkout 1.0.0

Одна сторінка замість шести кроків OpenCart. Цільова збірка: **ocStore 3.0.4.1 (українська)**. Той самий рушій стоїть на OpenCart 3.0.x і 2.3. Окремий каркас є для OpenCart 4.0.2+ / 4.1.

Замовлення збирається так само, як штатний `checkout/confirm`: ті самі totals, товари, affiliate, лист і модулі оплати. Порожній заказ не створюється, поки покупець не натисне підтвердження. Повторне натискання оновлює чернетку зі статусом 0, а не плодить дублі.

## Архіви

| Файл | Куди |
|---|---|
| `dist/storinka-v1.0.0-ocstore-3.0.4.1.ocmod.zip` | ocStore 3.0.4.1 і OpenCart 3.0.x |
| `dist/storinka-v1.0.0-opencart-2.3.ocmod.zip` | OpenCart 2.3.0.x |
| `dist/storinka-v1.0.0-opencart-4.ocmod.zip` | каркас OpenCart 4, без підміни живого checkout |

## Встановлення на ocStore 3.0.4.1

1. Розширення → Установник → завантажити `storinka-v1.0.0-ocstore-3.0.4.1.ocmod.zip`.
2. Розширення → Модулі → Storinka → Встановити → Редагувати.
3. Увімкнути статус і зберегти.
4. Розширення → Модифікації → Оновити. Подія ставиться кнопкою «Встановити» і працює навіть до оновлення модифікацій. OCMOD лишається запасним шляхом.
5. Вимкнути інші односторінкові оформлення (Simple, Ajax Quick Checkout, швидке оформлення теми).

Посилання «Стандартне оформлення» відкриває штатну сторінку з `storinka_off=1`, щоб перевірити платіжний модуль.

## Що налаштовується

- Поля: показ, обов'язковість, ширина, порядок. За замовчуванням для UA: ім'я і телефон обов'язкові, email необов'язковий, країна і регіон сховані і беруться з налаштувань магазину.
- Країна без регіонів не блокує доставку: `zone_id` стає 0, а не порожня валідація.
- Самовивіз (`pickup`) не питає адресу.
- Матриця `доставка = оплата`. Перший збіг виграє. Приклад: `pickup.pickup = cod`.
- Нова Пошта: коди методів, API-ключ, місто і відділення або поштомат. Без ключа лишаються звичайні поля. У замовлення пишуться місто і відділення, рядок НП додається в коментар.
- Купон, кількість у підсумку, маска `+380`, акцент і радіус.
- Кастомні поля акаунта й адреси OpenCart (крім типу file).

Мова адмінки і вітрини: uk-ua, ru-ru, en-gb. Для 2.3 додатково копії `ukrainian` і `russian`.

## Чого цей модуль не робить

Не підміняє HTML чужого модуля доставки всередині своєї верстки. Якщо Нова Пошта вже рахує ціну своїм модулем, Storinka забирає його quote і показує свої поля міста і відділення. Модулі, яким потрібен власний віджет у старому `shipping_address.twig`, треба або вимкнути, або лишити стандартне оформлення за посиланням.

OpenCart 4 у цьому релізі лише каркас: правильні namespace, `install.json`, подія і сторінка. Подія не підміняє checkout, поки в налаштуваннях немає службового ключа `module_storinka_oc4_live`. На 4.1 вже є своє односторінкове оформлення, а сесія замовлення інша. Робочі пакети зараз 3.0.4.1 і 2.3.
